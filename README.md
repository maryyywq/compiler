# Компилятор варианта 9

Учебный компилятор для языка варианта 9: главная программа C++, простейшие классы
с полями и методами без параметров типа void, типы int, float, bool, операции
арифметические, сравнения и логические, операторы пустой, составной, присваивания и if.

## Состав проекта

```
src/defs.h        коды лексем, исключения TError, TLexError, TSynError, TSemError
src/Scanner.h/cpp лексический анализатор (TScanner)
src/SemTree.h/cpp семантическое дерево (Tree, SemNode) и контроль контекстных условий
src/Parser.h/cpp  синтаксический и семантический анализатор (TParser)
src/main.cpp      точка входа: три этапа трансляции и печать дерева
tests/tests.cpp   автотесты синтаксического анализатора
tests/sem_tests.cpp автотесты семантического анализа и семантического дерева
tests/test_programs.txt программы для проверки 16 контекстных условий
input.txt         демонстрационная программа
docs/report_lab7.md текст отчёта по лабораторной работе
```

## Сборка

```
make
```

Появится исполняемый файл compiler. Очистка сборки:

```
make clean
```

## Запуск

```
./compiler input.txt
```

или через make:

```
make run
make run FILE=путь_к_модулю.cpp
```

Имя модуля можно передать аргументом командной строки, по умолчанию читается input.txt.

## Вывод программы

Если ошибок нет, печатаются три этапа трансляции и построенное семантическое дерево:

```
Лексический анализ выполнен
Ошибок нет
Синтаксический анализ выполнен
Ошибок нет
Семантический анализ выполнен
Ошибок нет

семантическое дерево:
  { глобальная область (строка 1)
    Point : класс Point (строка 7, позиция 7)
      visible : bool [private] (строка 10, позиция 10)
      ...
```

Если на каком-либо этапе найдена ошибка, печатаются вид ошибки, строка, позиция
в строке и сообщение, а выполнение прекращается:

```
Лексическая ошибка (строка 2, позиция 9): Неверный символ. Неверный фрагмент: "#"

Синтаксическая ошибка (строка 4, позиция 5): ожидалось: ;, а встретилось: идентификатор "a"

Семантическая ошибка (строка 5, позиция 9): несовместимые типы в присваивании: int = bool
```

## Тесты

```
make test
```

Запускаются два набора: синтаксические тесты (tests/run_tests) и семантические
тесты вместе с проверками семантического дерева (tests/run_sem_tests).
Каждый тест печатается одной строкой [OK] или [FAIL], в конце выводится общий итог.
Тесты контекстных условий читаются из tests/test_programs.txt, при запуске
вручную путь можно передать аргументом:

```
./tests/run_sem_tests tests/test_programs.txt
```

## Формат тестовых программ

Каждый тест в tests/test_programs.txt начинается строкой заголовка, за которой
идёт текст программы (строки нумеруются с 1 от начала программы):

```
// ТЕСТ: <название> | принято
// ТЕСТ: <название> | ошибка | <Л|С|М> | <строка> | <позиция> | <часть сообщения>
```

Л - ожидается лексическая ошибка, С - синтаксическая, М - семантическая.
Тесты сгруппированы по 16 контекстным условиям варианта 9.
